1. Put Bloop on the board

Plug the ESP32-S3-Touch-LCD-3.5-C into this computer with a USB data cable, then click Install. GitHub built this firmware from the latest code. Updating keeps what Bloop has already learned.

Installing needs Chrome or Edge on a computer. Installing needs this page to be opened over https.

Screen stays dark? Press the board's RESET button once after installing. If it's still dark, connect below and read the Board log: it says what the board found when it started. The screen test is a simpler program for checking the screen and touch.

2. Watch it learn

  1. After installing, close the install window. Then click Connect to Bloop (top right) and pick the board's USB port.
  2. Charts appear as Bloop makes choices, one every couple of seconds.

This browser can't talk to USB devices. Use Chrome or Edge on a computer.

How Bloop thinks, live

Bloop's brain is a Q-table, not a neural network: a grid of numbers it fills in itself as it lives. Its senses (left) pick one of 96 situations (middle). That situation's row of the table rates all 14 actions (right). Bloop usually picks the best one, sometimes a random one to learn something new. Line thickness shows how strongly it believes in each action: blue = expects good things, red = expects bad things.

How it learns

This loop repeats every couple of seconds, forever. Each lap nudges one number in the table.

Bloop's voice: a tiny language model

This part is a neural network: a tiny transformer, the same kind of model as large language models, just about 2,000 times smaller than GPT-2. GitHub trains it on example lines every time the code changes, and it runs on the board itself. It reads how Bloop feels and what just happened, then writes one word at a time, feeding each word back in to choose the next.
